The **memory that is independent of the address bus is Cache Memory.**

### Simple Explanation

* **Main memory (RAM)** needs the **address bus** to find data.
* The CPU sends an **address through the address bus** to RAM to get the data.

But **cache memory works differently**:

* Cache is **very close to the CPU**.
* The CPU **checks the cache directly** using a **tag system**, not by sending the address through the main address bus.
* Because of this **internal checking**, cache does not depend on the **system address bus** like RAM does.

### One Line for Exam

**Cache memory is independent of the address bus because the CPU accesses it directly using cache tags instead of the system address bus.**
